# Durga Particle Animation

An interactive Python application that creates a visually stunning particle animation using an image of Goddess Durga. Built using Python, Pygame, and OpenCV.

---

## 📋 Features
- Real-time particle system rendering.
- Converts image pixels (`durga.png`) into dynamic animated particles.
- Smooth animation powered by Pygame.

---

## 🛠️ Requirements & Prerequisites

Make sure you have **Python 3.x** installed on your system. You will also need the following Python libraries:

- `pygame`
- `opencv-python`
- `numpy`

---

## 🚀 Step-by-Step Installation & Setup

### 1. Folder Setup
Ensure that both `main.py` and `durga.png` are placed inside the same project folder:

```text
Durga_Project/
│── main.py
└── durga.png
```

### 2. Install Required Libraries
Open your Command Prompt or Terminal and run the following command to install the required modules:

```bash
pip install pygame opencv-python numpy
```

---

## 🎮 How to Run the Project

1. Open your terminal or command prompt.
2. Navigate to your project directory (e.g., if saved on the Desktop):

   ```powershell
   cd Desktop\Durga_Project
   ```

3. Execute the Python script:

   ```bash
   python main.py
   ```

---

## ❓ Troubleshooting

- **Error: `No such file or directory`**
  - Ensure `durga.png` is inside the same folder as `main.py`.
  - Make sure your terminal path is set to the correct directory before running the command.

- **Error: `ModuleNotFoundError`**
  - Re-run the library installation command: `pip install pygame opencv-python numpy`.
